✨ Key Features

🔐

Hardware Licensing

Machine-locked licenses prevent piracy. Each installation is tied to specific hardware.

👥

11 User Roles

Granular permissions for Super Admin, Head Teacher, Bursar, Class Teacher, and more.

📱

Parent Portal

QR code access for parents to view reports, attendance, and fee status on their phone.

📄

Report Cards

Auto-generated PDF report cards with school branding, rankings, and teacher comments.

💾

USB & Cloud Backup

Automatic weekly USB backups and silent Google Drive sync for disaster recovery.

Super Admin Control

Enable/disable features per school. Pay-per-term licensing model.
